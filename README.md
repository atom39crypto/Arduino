IoT Basics – Beginner Projects
**📌 Overview**

This repository contains my first foray into the Internet of Things (IoT).
It includes a collection of small, hands-on projects designed to understand how sensors, actuators, and microcontrollers interact with the physical world.

These projects focus on building strong fundamentals in embedded systems, electronics, and basic automation.

🔧**Projects Included**

**1) 7-Segment Display**
      Displaying numerical outputs using a 7-segment display controlled by a microcontroller.

**2) Tilt Detector (LED)**
      Detecting device orientation and triggering an LED based on tilt.

**3) Tilt Buzzer**
      Activating a buzzer when a tilt condition is detected.
  
**4) Photo Sensitivity**
      Using a light sensor to respond to changes in ambient light.
  
**5) Switch-Controlled LED**
      Basic digital input handling using a physical switch.


**🛠️ Technologies & Components**

> Microcontroller (e.g., Arduino)
> LEDs, Buzzers, Switches
> Tilt Sensor
> Photoresistor (LDR)
> 7-Segment Display
> Embedded C / Arduino IDE

**🎯 Learning Outcomes**

> Understanding digital and analog inputs
> Working with sensors and output devices
> Basic circuit design and debugging
> Writing simple embedded programs
> Interfacing hardware with software logic

**📽️ Demonstrations**

Each project includes a short demonstration video showing the working setup and output behavior.

**📖 Notes**

This repository represents learning-focused projects and is intended to document my early exploration into IoT and embedded systems.
